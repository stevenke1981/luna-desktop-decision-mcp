# Windows 原生多行文字輸入實測

2026-11-19，Windows 11 build 26300，AMD64，CPython 3.14.9。以隔離行程中的標準 Win32 多行 Edit 控制項為目標。每次測量前清空測試欄位並核對前景視窗及焦點。測試結束後確認原前景視窗已恢復。

輸入為固定的 819 字元多行文字，以 UTF-8 讀取並移除末尾一個換行。SHA-256 為 `04fae1b5bffc0c19c24c8673c9a1b395fc2d6292232aa34bd27577292e7716ea`。計時涵蓋單次 `desktop.execute` 及其中的原生欄位讀回，包含獨立 MCP 呼叫、模型判斷或瀏覽器的端到端流程均為 `NOT_RUN`。每次呼叫結束後另取一份欄位內容，將 Win32 的 CRLF 轉為 LF 並核對全文。
